Regular expressions
===================

Include <regexp.h> and link regexp.lib to use the Henry Spencer V8-style
regular-expression engine used by the Helios text utilities. This is not
the POSIX <regex.h> interface.

regcomp(pattern) compiles an expression and returns NULL on error. Free the
returned expression with free() when finished. regexec(expression, text, bol)
returns nonzero for a match; bol is nonzero when text starts at the beginning
of a line. Captured groups are recorded in the expression's startp/endp arrays.
regsub(expression, replacement, output) expands a replacement using the most
recent match; the caller must provide enough output space.

The default regerror(message) reports errors to stderr. An application may
provide its own callback. Compilation and matching use internal global state;
serialize calls when using the library from multiple threads.
